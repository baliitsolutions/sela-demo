Sela — Yoga & Pilates Studio Landing Page

Thank you for your purchase. This guide covers everything you need to put the template online with your own content. No build tools are required: open index.html in a browser and you're running.

Change colours and fonts

Open assets/css/style.css and edit the variables in :root. The hero sky, sun, buttons and dark sections all follow them.

:root {
  --ink: #2b2a4c;   /* headings, dark sections, horizon lines */
  --mist: #ece7f6;  /* tinted sections */
  --sun: #f5b84a;   /* buttons and the sun */
  --peach: #fde4c8; /* bottom of the hero sky */
}

Each class type also has its own colour (--c-vinyasa, --c-yin, --c-reformer, --c-prenatal), used in the class list and timetable.

To change fonts, replace the Google Fonts <link> in index.html and update --font-display and --font-body.

Edit your timetable

The whole timetable comes from SCHEDULE at the top of assets/js/main.js. Each day (0 = Sunday … 6 = Saturday) has a list of classes:

1: [
  { time: "07:00", mins: 60, type: "vinyasa", teacher: "Ana", spots: 4, capacity: 12 },
  ...
],
  • time: 24-hour start time
  • mins: class length in minutes
  • type: one of the keys in CLASS_TYPES
  • spots / capacity: places left and total places. With 2 or fewer left the line turns amber; with 0 the class shows as full.

The day tabs always start from today and show the next seven days. Classes that have already started today are marked "Started". The "Next class" line in the hero updates from the same data.

Add or rename a class type

  1. Add it to CLASS_TYPES in main.js, for example hot: { name: "Hot Yoga", color: "var(--c-hot)" }.
  2. Add the colour --c-hot in :root of style.css.
  3. Add a filter button in index.html: <button type="button" class="chip" data-filter="hot" aria-pressed="false">Hot</button>
  4. Optionally, add a card for it in the Classes section.

Connect real bookings

In the template, the Book button opens a demo dialog and marks the class as booked in the visitor's browser. Most studios use a booking system such as Mindbody, Momence, Glofox, Arketa or Calendly. To send visitors there, replace the body of openBooking() in main.js with a link:

function openBooking(c, d) {
  window.open("https://your-booking-page.example.com", "_blank");
}

Receive trial sign-ups

The trial form validates and shows a confirmation, but doesn't send anything yet. Sign up for a form service such as Formspree, Getform or Netlify Forms and add its URL as the form's action:

<form class="trial-form" novalidate data-trial-form
      action="https://formspree.io/f/your-id" method="POST">

Add teacher photos

Each portrait shows initials until you add an image:

<div class="portrait" data-initials="AN"
     style="background-image:url('assets/img/ana.jpg')"
     role="img" aria-label="Photo of Ana Navarro"></div>

Portrait images around 900 × 1200 px work best. The arched top is applied automatically.

Edit text, prices and contact details

All content is plain HTML in index.html, grouped by commented sections (HERO, CLASSES, PRICING and so on). Search for and replace Sela Studio, hello@example.com, (555) 018-8300 and 21 Linden Street.

Publish

Upload the whole folder to any static host: Netlify, Vercel, GitHub Pages, Cloudflare Pages, or the public_html folder of regular web hosting.

Browser support

Current versions of Chrome, Edge, Firefox and Safari, on desktop and mobile. Keyboard accessible, and the sunrise animation is switched off for visitors who prefer reduced motion.
