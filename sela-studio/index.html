    Before your first class

    I've never done yoga. Which class should I take?

    Start with Yin & Restore or any Vinyasa marked "all levels". Tell your teacher it's your first time and they'll offer easier options.

    What should I bring?

    Comfortable clothes and water. Mats, blocks, blankets and towels are all provided.

    How early should I arrive?

    Ten minutes before your first class, so we can show you around and set up your space.

    What's the cancellation policy?

    Cancel up to 8 hours before class for a full credit. Later cancellations use up the class.
